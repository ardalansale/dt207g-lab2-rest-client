# DT207G – Laboration 2 – REST‑klient för arbetserfarenheter
En fristående HTML/CSS/JavaScript‑webbplats som konsumerar REST‑API:t från Laboration 2.
Byggd med ren frontend‑teknik utan Express/EJS.

## Publicerad webbplats
[Frontend‑URL vid deploy]

## GitHub‑repo
https://github.com/ardalansale/dt207g-lab2-rest-client

## Funktionalitet
- Visa alla arbetserfarenheter (GET)
- Lägga till nya poster via formulär (POST)
- Radera poster (DELETE)
- JavaScript‑validering av obligatoriska fält
- Tydliga felmeddelanden
- Minimalistisk design

## Sidor
- index.html – listar alla poster
- add.html – formulär för att lägga till poster
- about.html – info om webbplatsen och databasval (Railway)

## Tekniker
- HTML
- CSS
- JavaScript (Fetch API)
- Railway PostgreSQL (via REST‑API)

## Installation
Ingen installation krävs.
Öppna index.html i webbläsaren eller deploya till Vercel/Netlify.
